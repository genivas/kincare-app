Como Instalar no Celular em 30s

Guia de instalação PWA sem precisar de App Store

No iPhone (Safari):

  1. Abra este site no navegador Safari.
  2. Toque no botão de Compartilhar (quadrado com seta para cima).
  3. Selecione "Adicionar à Tela de Início" e confirme.

No Android (Chrome):

  1. Abra este site no Google Chrome.
  2. Toque nos 3 pontinhos (⋮) no canto superior.
  3. Selecione "Instalar aplicativo".

Como funciona o Backup:

Para trocar de celular ou salvar suas consultas no computador, clique em "Exportar Backup". Um arquivo JSON será salvo no seu dispositivo. No celular novo, clique em "Importar Backup" e selecione o arquivo para restaurar tudo instantaneamente!
